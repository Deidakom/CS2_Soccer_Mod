# CS2 SoccerMod v1.0-Beta-Official

The mod's first release explicitly labelled and versioned as **v1.0 Beta**
(in-game credits now read "CS2 SoccerMod v1.0 Beta" instead of an internal
dev version string), consolidating everything since v1.1.0 plus one new
gameplay fix.

## Fixed

- **Instant body push at round start.** Every round start freezes the ball
  (`DisableMotion`) so it can't creep before anyone touches it; only a real
  touch releases it. Kicks always reached that release, but a *body* push
  only reached it after an approach-speed check — and a frozen ball is a
  static wall to the movement code, so the engine clipped the player's
  velocity to zero on contact and the check never passed. Result: walking
  into the ball right after `!match start` or a kickoff restart blocked it
  for about a second before it became pushable. The first eligible body
  contact now releases the ball immediately, and the push follows on the
  very next tick — the same feel as touching a ball already at rest.
- Warmup goals that aren't own goals no longer reset the ball to centre —
  it's left where it landed. Own goals are unchanged.
- Fixed jumping over the ball: the body-push and body-impact physics no
  longer act on a player whose feet have already cleared the ball's top
  surface, so a jump that clears the ball (a normal jump does) is no
  longer shoved back down onto it. Ball size is unchanged.
- Fixed AFK snapshots retaining live entity memory; poll once per second
  and reuse the player list instead of scanning twice every tick.
- Preserve assists during repeated dribble touches, clear ball-touch credit
  on ball resets/disconnects, and clear per-match stats at the next start.
- Fixed KICKOFF (the optional self-hostable cap website) database
  connection cleanup, malformed session handling, login redirect
  validation, fragmented/multi-packet RCON responses, and concurrent RCON
  batch imports.
- The SoccerMod menu UI was reverted back to its pre-redesign layout
  (fonts, padding, page capacities, navigation) after a same-day
  experiment; see `docs/deployments/2026-09-05-menu-ui-revert.md`.

## Added

- Ball menu: new "Restore defaults" entry (confirm-gated) and
  `css_sm2ball_defaults` console command, resetting spin, air-kick,
  left/right-click power, body-push, kick sound, impact, settle and
  elevation to their defaults in one step.
- The missing KICKOFF environment template, persistent writable data
  volume, explicit bridge gateway, and separate service credentials.
- Established the official community page: the Steam group
  [cs2soccermod](https://steamcommunity.com/groups/cs2soccermod), linked
  from the README and the in-game `!menu -> Help -> Project links`.
- Python and managed regression test coverage refreshed and expanded.

## Changed

- Index stats by SteamID and save on map end and plugin unload. Restore
  temporary AFK passwords and goal-respawn settings on those exit paths.
- Ball collision group reverted to 0 (regular solid) — group 20
  (non-solid to players) didn't help the jump-over issue and is no longer
  needed now that the push/impact fix addresses it directly.
