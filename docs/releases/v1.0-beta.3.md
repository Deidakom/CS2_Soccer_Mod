# CS2 SoccerMod v1.0 Beta.3

Small visual follow-up to Beta.2.

## Changed

- Replaced CS2's large native defuse-style sprint cooldown indicator with a
  subtle ten-segment bar that counts down twice per second.
- The sprint bar does not draw while the SoccerMod menu is open, avoiding HUD
  overlap. The persistent per-player enable/disable setting is unchanged.

All sprint speed, duration, and cooldown values remain identical to SoMoE.
