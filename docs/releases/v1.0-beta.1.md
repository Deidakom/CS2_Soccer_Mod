# CS2 SoccerMod v1.0 Beta.1

Patch release for the first public beta.

## Fixed

- Website CAP assignments can now be explicitly cleared when a CAP ends.
  Clearing restores the player's prior clan tag, removes the temporary
  position, and stops forced T/CT assignment and respawning.
- Added the server-only `css_sm2webcap_clear` command for authenticated CAP
  coordinators. The public KICKOFF service uses it when a CAP is dismissed,
  emptied, expires, leaves test mode, or a fresh CAP is opened.
- Stock T/CT uniform models are now added to the map precache manifest so the
  optional uniform-model mode does not fail with a "requested but not
  resident" resource error on the Workshop stadium.

The plugin still identifies itself in `css_plugins list` as
`CS2 SoccerMod (1.0 Beta)`; this is a compatible beta patch.
