# CS2 SoccerMod 1.5.0 — drop-in release

**New: copy it into your server and it runs.** The Linux and Windows ZIPs
now carry everything a fresh CS2 server needs: Metamod:Source 2.0 (build
1469), CounterStrikeSharp v1.0.375 with its .NET runtime, MultiAddonManager
v1.6.1, SoccerMod with its ball-physics bridge, and the server configs.

## Install

1. Stop the server, copy everything from the ZIP's folder into your CS2
   server folder (the one that contains `game`).
2. Run `bash install.sh` (Linux) or `install.bat` (Windows) once. It adds
   Metamod's line to `game/csgo/gameinfo.gi` (with a backup).
3. Start the server with any map; SoccerMod switches to the stadium
   (Workshop 3361075564) by itself.
4. From the server console: `css_admin_add <your SteamID64> root`.

Run the installer again after every CS2 update.

| File | For |
|---|---|
| `CS2-SoccerMod-1.5.0-linux.zip` | fresh Linux server (glibc 2.31+) |
| `CS2-SoccerMod-1.5.0-windows.zip` | fresh Windows server — **beta** |
| `CS2-SoccerMod-1.5.0-server.zip` | plugin only, for servers with Metamod + CounterStrikeSharp |

**Windows is beta.** The ball-spin bridge is ported to Windows in this
release and builds on GitHub's Windows runners, and the installer is tested,
but it has not run on a live Windows game server yet. Without the bridge the
mod plays normally, only without ball spin. Please report problems in the
issues.

## What's new since 1.1.0

- **3D grass** on SoccerMod-sized pitches, per player on/off in
  `!menu → Settings → Visuals` (on by default), lit piece by piece so the
  stadium roof shadow shows on it.
- **Match scoreboard** at the top of the screen with kick-off, goal,
  half-time and full-time banners; covers CS2's own top bar. Two layouts per
  player: Full (team names) or Compact (`!menu → Settings → Match`).
- **Settings grouped**: Match, Sprint, Visuals, Sounds, Menu.
- **Ball menu**: a simple view with the important dials (power, kick reach
  and cone, top speed, gravity, bounce, size) plus the full advanced view.
- **Goals**: the ball stays in the net until the round restart, nobody is
  killed any more, the net sound plays on every goal.
- **Kick-off**: kicks on the frozen kick-off ball keep their full speed;
  walking up to it no longer makes it roll or start the clock.
- Sprint chat messages off by default; no shards or dust when the knife hits
  the ball; knife reach 64 / cone 40° as the served default.
- Portable Linux bridge (glibc 2.14+ symbols, built on Ubuntu 20.04) for
  hosts like myarena; automatic stadium map switch on a fresh server
  (`css_sm2_automap off` to stop it); a server without the bridge plays
  without spin instead of printing console errors.

Players get menus, kits, sounds, HUD and grass from the Workshop item
[3797479770](https://steamcommunity.com/sharedfiles/filedetails/?id=3797479770);
MultiAddonManager sends it to everyone who joins.
