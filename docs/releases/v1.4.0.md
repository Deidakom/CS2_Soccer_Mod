# CS:S menu catch-up 1.4.0

Adds the missing server-side ranking, statistics, ready-check, CAP, administration
and training controls. Keeps the existing ball profile and introduces no ball
physics tuning changes.

- Competitive Top 50 history survives full time and is backed by a separate JSON
  file that older plugin versions do not rewrite. Public and competitive views
  support totals, per-round and per-match averages, personal details and explicit
  personal reset confirmation. Existing public totals remain intact; old missing
  competitive history is not invented.
- Statistics include team, player, round and match views, possession time, round
  MVP (+15 points, matching the CS:S reference), connection/play-time records and
  personal pass/save/loss chat filters. Full time counts eligible participants
  correctly even after the match state changes to Finished. The existing warmup
  rule (goal effects without match/stat bookkeeping) remains intact.
- Pauses freeze the current ball in place, block player kicks/pushes and resume
  its saved linear motion after the countdown. Frozen kickoff balls stay frozen
  until their first legitimate touch.
  Motion uses measured VPhysics velocity and preserves scorer/assist history.
- Ready checks use SteamID and team identity, offer Ready/Not Ready and Off,
  Auto or Manual modes. Auto waits for the paused roster; disconnected players
  require an explicit resume override. New unready players cannot be skipped.
- Optional CS:S stoppage ends on the ball returning to halfway or a goal. Legacy
  immediate period ending remains selectable. Log schedules support selected
  days, overnight windows and server-local times. Pause/period categories and
  individual match-start information announcements are configurable.
- CAP has configurable team size, connection-order first-player rules, pre-CAP
  signup (`!capjoin`), roster view and enforced assignments through the match.
  Picks validate the captain, turn, target SteamID, spectator status and capacity
  again when selected. Captain departure cancels an unfinished draft.
- Root-only offline SteamID64 flag editor with confirmation and revalidation.
  Existing SoccerMod/admin/match/ball/root separation remains in force. Optional
  three-level public control policy defaults to the current free Match/CAP
  behavior; the server's separate restricted-main-menu switch remains available.
- Training adds verified native CS2 cone, can and plate resources; scored hoop
  outlines, goal targets, positioning, saved layouts and advanced training mode.
  Devices are bounded and cleared on restart, match start, disconnect and unload.
  Starting a match always re-enables goals. Original CS:S prop art is not claimed.
- Recent sound-event browser supports blocking/unblocking observed hashes. Global
  match/CAP/training announcements now follow configured chat prefix/colors.
- Optional CS:S celebration weapons use the existing CS2 weapon substitutions,
  a bounded post-goal window and restoration of friendly-fire/knife state.
  Disabled by default.
- Fix zero-second break persistence, stale admin-promotion callbacks and sprint
  HUD visibility when match information is disabled.
- Defer existing-player statistics enumeration to hot reload, since engine
  globals are unavailable during cold plugin startup.

Configuration changes are saved through the existing atomic writer. Public ranks,
competitive history, admin/ban data and saved layouts are retained during binary
rollback. The deployment installer accepts `preserve` as its third argument to
leave the selected ball profile intact during menu-only upgrades.

The [current parity audit](../css-menu-parity-2026-09-05-v1.4.md) records the
remaining client-asset and engine differences. Compilation and headless tests
cannot prove menu visibility, input handling or how the new props feel in play.
The [German deployment report](../deployments/2026-09-05-parity-completion.md)
records live checks and the exact pre-release rollback command.
