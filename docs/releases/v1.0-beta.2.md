# CS2 SoccerMod v1.0 Beta.2

Feature and compatibility update for the public beta.

## Added

- Native SoMoE-style sprint cooldown progress bar using CS2's replicated
  defuse-bar fields. It begins when the three-second sprint ends and tracks the
  original 7.5-second cooldown.
- Persistent per-player progress-bar setting in `Menu > Settings`, also
  available through `css_sprintbar`. It is enabled by default and independent
  from sprint chat messages.

The plugin remains compatible with the v1.0 Beta configuration and still
identifies itself as `CS2 SoccerMod (1.0 Beta)` in `css_plugins list`.
