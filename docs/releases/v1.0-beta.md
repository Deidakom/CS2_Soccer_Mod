# CS2 SoccerMod v1.0 Beta

The first installable public beta of the CS2 port of SoMoE-19 Soccer Mod.

## Included

- Native VPhysics soccer ball and knife-kick controls.
- Standing and crouched kick power, airborne kick normalization, wall-bounce
  tuning, ball/player impact, and goal/reset handling.
- Match, referee, admin, AFK, sprint, goalkeeper-area, stats, and ranking tools.
- Red T and blue CT player tinting with uniform stock team models and separate
  persistent admin toggles.
- HTML/classic number-key menu and stadium radar/loading resources.
- KICKOFF website cap bridge with automatic team assignment, respawn, and
  temporary position tags.
- Compiled plugin and all required SoccerMod resources in one server archive.
- Checksum verification, safe upgrade backups, Linux installer, manual Windows
  instructions, and a server cfg example.

## Requirements

- A CS2 dedicated server with Metamod:Source 2.x.
- CounterStrikeSharp 1.0.373 or newer with .NET 10 plugin support.
- Workshop item `3361075564` (`soccer_cssl_stadium_v8`).

## Important beta notes

- This is a prerelease. Test it before putting it on a production server.
- Third-party dependencies and the Workshop map are not bundled.
- Fresh installations contain no administrator. Use server console/RCON:
  `css_admin_add <steamid64> root`.
- The public KICKOFF site targets the community server. Other server owners may
  integrate the server-only bridge commands with their own cap coordinator.

Download `CS2-SoccerMod-v1.0-beta-server.zip`, verify its adjacent SHA-256 file,
and follow the README inside the archive.
