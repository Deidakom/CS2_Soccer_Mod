# CS2 SoccerMod 1.6.0

One Workshop item is all a server needs now, and the mod has three of our own maps.

## Install

Same as 1.5.0: copy the ZIP's folder into your CS2 server, run `install.sh` /
`install.bat` once, start the server. The server configuration
(`examples/multiaddonmanager.cfg`) loads one Workshop item:

```text
mm_extra_addons "3811382872"
```

[`3811382872`](https://steamcommunity.com/sharedfiles/filedetails/?id=3811382872) is
`soccer_soccermod_arena`: the stadium map and everything the plugin shows and plays - menu,
kits, sounds, HUD, stadium effects. Players receive it when they join. It replaces the
Feature Package 3797479770 and the v8 map 3361075564 as requirements. Servers that still use
them keep working; a fresh install should use the item above.

## What's new since 1.5.0

- **Our own maps**: the SoccerMod stadium (the default; a fresh server switches to it by
  itself), the indoor hall `soccer_indoor_hall` (3 to 4 players a side, 3811545272) and the
  2v2 hall `soccer_2v2_arena` (3811585232). The admin map list offers the other two.
- **Kick feel**: a click kicks in the tick it is made (it used to wait one tick). New options:
  the exact CS:S knife area as a kick cone preset, and a kick lag compensation (off by default).
- **Ball**: 20% smaller by default (was 13%).
- **Sounds**: the referee whistles are on; crowd background, reactions, chants and announcer
  are opt-in per player.
- **Map reload for everyone** while public access is "CAP / Match".
- **Number-key menu without binds** (new, off by default: `css_sm2menu_keys on`): the radio
  key opens the football calls, the SoccerMod menu opens with the menu command and is driven
  with the keys 1-9. It needs `resource/ui/radiopanel.txt` from the Workshop item.
- Stadium effects on the indoor hall: its own fans cheer, goal show in hall positions.
- Own goals are celebrated by the team that gets the goal; the 3D grass shows the white lines.

Windows is still beta (no live game server run of the Windows ball-spin bridge yet).
