# SoccerMod menu catch-up 1.3.0

Restore the missing kickoff-wall controls and visible center-circle boundary,
expose working server settings in the in-game menu, and port Sprint 2.0 stamina
and personal hold/toggle/HUD controls. Add persistent forfeit/log/info settings
and menu access to ball profiles and training drills. Menus remain open until
closed and sprint HUD output no longer competes with an open menu.

This is not a complete CS:S port. The [menu audit](../css-menu-parity-2026-09-05.md)
records the remaining asset, ranking, administration, match and map differences.
The legacy ball, kickoff and sprint switches and a complete pre-deployment
binary/config snapshot provide separate rollback paths.
