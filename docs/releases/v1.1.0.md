# CS2 SoccerMod v1.1.0

The first release with the native physics bridge included, real ball
spin, and three SoMoE menus rebuilt 1:1: Cap, Match, and Training.

## Added

- **Native Metamod plugin** (`soccermod_native`, Linux): a typed
  `ApplyAbsVelocityImpulse`/`ApplyLocalAngularVelocityImpulse` bridge for
  the ball. This is what makes kick and wall-rebound **spin** real
  (`css_sm2ball_spinfactor`, default 1.0). Packaged and installed
  automatically from now on — previous releases didn't include it.
- **Cap menu**, rebuilt 1:1 against the original SoMoE `cap.sp`: put
  everyone to spectator, add a random player, start a captain-pick fight
  (28-weapon selection, countdown, first elimination decides the two
  captains), then alternating picks from `[Join Nr] Name [Positions]`.
  Positions are the original seven Yes/No toggles, persisted per player.
- **Match menu**, rebuilt 1:1 against `match.sp`: Start/Stop and
  Pause/Unpause toggles, a full Match Settings tree (period/break length
  presets + custom via chat, Golden Goal, team names with clan-tag
  picking), and a live-refreshing Match Log. Open to everyone, matching
  the original's public-mode behavior.
- **Training menu** (`training.sp` + `training_personalcannon.sp`):
  Cannon (position/aim/on/off/settings, fires the match ball on a timer),
  Personal Cannon (same, with your own private ball), Spawn/Remove Ball,
  and Disable/Enable Goals so training shots don't trigger the warmup
  goal-kill.
- Chat-based value entry for menus that need a number or text (period
  length, team names, cannon settings) — type the value directly in chat
  after selecting an entry, exactly like the original mod.

## Fixed

- **Goal detection accepted shots that missed the goal entirely.** The
  aperture was 73 units wider than the real posts (measured via a new
  `css_sm2goal_measure` trace: posts at ±127, not the old guess of ±200)
  and had no real goal-line concept, only "60 units in front of the net."
  Goals now require the ball's centre to cross a measured goal line by a
  full ball radius, only when entering the goal (not leaving it), and a
  rejected crossing logs the reason (`wide`/`high`/`low`) for anyone who
  wants to verify their own map's calibration.
- Body-push, ball/player impact, and kick-contact physics tuned closer to
  the original CS:S feel (opposing-motion cancel, airborne kick scaling,
  wall-rebound re-spin, +50% body push).
- Warmup own-goal punishment now fires as a visible, immediate kill
  instead of a silently-swallowed one (a godmode hook was blocking
  self-inflicted kills, which also silently broke `!kill`/slay under
  default settings — fixed for both).

## Changed

- Match and Reload Map moved from the Admin menu into the main menu —
  their commands were already open to everyone.
- A three-tier admin system: `match` < `admin` < `soccermod` (implies
  `admin`+`match`) < `ball` < `root`. Promote/demote the `soccermod` tier
  directly from `!menu → Admin → Player Promotion`.
- Kick/Ban/Suspend moved into a single Punish Player menu with a rights
  matrix (kick/slay/suspend for `soccermod`+, permanent ban for `root`).

## Known limitations

- Ball spin needs the native Linux plugin — Windows servers run
  everything else but without spin.
- Two SoMoE training features are not ported: Spawn Prop Menu and
  Advanced Training (goal targets) — both depend on training prop models
  this port doesn't ship.
