# CS2 SoccerMod 1.7.0

The state our own servers ran on 2026-10-03, as a release.

## Install

Same as 1.6.0 (copy the ZIP into the server, run `install.sh` / `install.bat` once). No extra
Workshop item is needed any more: every SoccerMod map item carries all content - menu, kits,
sounds, HUD, effects - so `mm_extra_addons` can stay empty when you play our maps:

| Map | Workshop |
|---|---|
| `soccer_soccermod_arena` (stadium, default) | 3811382872 |
| `soccer_indoor_hall` (4v4) | 3811545272 |
| `soccer_2v2_arena` | 3811585232 |
| `soccer_street_arena` (3v3) | 3811797781 |
| `soccer_1v1_cage` | 3811824498 |

On a map that is not ours, put one of these items into `mm_extra_addons` as the content source.

## What is new since 1.6.0

- **Number-key menu without binds, on by default**: the radio key opens the football calls, the
  menu command opens the SoccerMod menu and the keys 1-9 drive it after one press of the radio
  key. Match, Cap, Training, Referee and Reload Map are on the first page. `css_sm2menu_keys off`
  brings the old menu back.
- **Two new maps**: street arena and 1v1 cage; the 2v2 hall was reworked.
- **HOME / AWAY** instead of RED / BLUE on the scoreboards; ball shadow on the hall maps.
- **Brand boards** in the stadium and the halls.
- In the code, switched off: the CS:S ball driver (needs its helper program, not part of this
  package), football mode, a floating score banner, the kick area outline for tuning.
