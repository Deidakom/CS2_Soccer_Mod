	// (KeyMenu.cs in the server plugin).
	//
	// The client's radio panel takes the raw number keys while it is open - no binds needed.
	//
	// The stock radio key (Z) opens "common": the football calls ("Pass here!" ...), drawn by the
	// client. A key sends the call to the server and opens "group", an empty panel that catches
	// the number keys for a short moment: the server draws the calls again over it, so another
	// call is one key press away, then everything is gone.
	//
	// The SoccerMod menu itself is opened with the menu command (!menu). The server draws its
	// pages (soccermod_keymenu.xml) in the place of this panel; with the radio key pressed once,
	// the number keys reach the page that is open: the server takes a key from any of these
	// groups for the open page. "standard" is the key catcher for the menu pages - every key
	// press there opens it again, so the menu stays usable key after key.
	//
	// Key 0 is always the game's own Exit: it closes the panel and sends nothing. The server
	// closes its page after the same time without a key press ("timeout" of "standard" =
	// KeyMenuTimeoutSeconds, "timeout" of "group" = KeyMenuCallSeconds).
	//
	// The entries of "common" must stay in the order of FootballCalls (Calls.cs). A server whose
	// plugin does not know css_call ignores it; css_N is the old number-key command.
