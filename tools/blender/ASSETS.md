# Prop and texture sources

Everything in `tools/blender/props` and `tools/blender/materials` is generated by our own scripts.

## ChatGPT textures (owner's ChatGPT Plus account, 2026-10-18)

The owner asked to regenerate the low-detail textures with ChatGPT images. The pictures are in
`C:/Users/sergi/Documents/AI/arena-ai-textures/` (`raw/` = as downloaded, 1254 px; the folder itself =
prepared by `ai-textures.mjs`: seamless, 2048 px). They are not in git. `aiTexture(name, recipe)` in
`matlib.mjs` uses the picture when it exists and the generated recipe otherwise, so a build without the
folder still works (with the old look). Override the folder with `SM_AI_TEXTURES`.

| picture | used by |
| --- | --- |
| plaza_stone | plaza paving round the stadium |
| plaza_granite_dark | monument plinth |
| lawn_grass, hedge | lawns, hedge round the plaza |
| plaza_medallion | football mosaic in front of the open gates |
| concrete, concrete_wall | stadium concrete, concourse walls, planters |
| facade, roof_ceiling | stadium cladding and roof underside |
| tunnel_wall | players' tunnel walls, dark steel |
| floor_rubber, floor_concourse, floor_tile, ceiling_tile | interiors |
| wood, steel_brushed, bronze | counters, lockers, benches, trusses, monument |
| bark, leaves | trees |
| screen_led, tactics_board | fan zone screen, locker room board (pictures, mapped once per object) |

Prompt pattern for the tileable ones: "Generate one single image (one texture only, not a collage): a
seamless tileable flat top-down PBR albedo texture of ..., evenly lit, no shadows, no perspective,
square, photorealistic." One fresh chat per picture (in a long chat ChatGPT started making collages).

To add one: generate it, save it as `raw/<name>.png`, run
`node tools/blender/ai-textures.mjs raw/<name>.png <name>` (`--tile 0 --aspect keep` for pictures),
then point a material at it with `aiTexture("<name>", <fallback recipe>, <bump>)`.
